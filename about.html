Spectrolipi

Bioacoustics Visualization and Annotation Suite
What is Spectrolipi?

Spectrolipi is an open-source, privacy-focused bioacoustics annotation tool built for researchers, birders, and machine-learning practitioners. It supports full audio spectrogram playback, manual and template-assisted annotation, species labeling, metadata management, audio cutting/filtering, and automatic identification using the BirdNET AI classifier.

No installation is required. To protect data privacy, all audio processing and neural network calculations are executed locally in the browser. No audio data ever leaves your computer.

Dependencies & Software Libraries
  • TensorFlow.js
    Google's open-source machine learning framework for Javascript. Used to run local BirdNET model inference inside the browser.
  • Tabulator
    An interactive grid library used to manage, sort, edit, and filter bird annotations in real-time.
  • FontAwesome & Google Fonts
    Provides UI icons and typography (Inter, JetBrains Mono) to ensure a clean, responsive layout.
